# R Data Analysis Portfolio Demonstration

This project demonstrates an R workflow using synthetic data generated inside the R Markdown file. It showcases data preparation, merging, validation, descriptive statistics, visualisation, group comparisons, effect sizes, categorical association tests, and correlation analysis.

## Important data note

The data are synthetic and created for demonstration only. The output is not a report of real student data and must not be interpreted as real-world findings. This demo does not include the original capstone dataset or report.

## Files

- `r-analysis-portfolio-demo.Rmd` — self-contained analysis source.

## Run it

1. Open the `.Rmd` file in RStudio.
2. Install any missing packages: `tidyverse`, `janitor`, `effectsize`, and `rmarkdown`.
3. Select **Knit** to render the HTML report.

## Skills demonstrated

- Data creation, inspection, cleaning, and joining
- Checks for unique IDs and missing values
- Descriptive and grouped summaries
- Data visualisation with `ggplot2`
- Welch's t-test and Cohen's d
- Chi-square test
- Spearman correlation
- Reproducible reporting with R Markdown
